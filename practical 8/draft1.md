# Draft 1: User Stories

## US-01: Create an account

**Requirement:** REQ-01

**As a** visitor, **I want** to register for an account, **so that** I can use
the portal.

### Acceptance criteria

- Given I enter a valid email and password, When I submit the form, Then my account is created.

## US-02: Sign in

**Requirement:** REQ-02

**As a** user, **I want** to sign in, **so that** I can access my account.

### Acceptance criteria

- The user should see an error if sign-in fails.
